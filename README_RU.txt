AKYR Client — настоящий запускатель Minecraft Java Edition 1.21.4 (Windows)

Что умеет:
- Интерфейс с кнопкой «ИГРАТЬ».
- При первом запуске скачивает файлы официальной версии Minecraft Java 1.21.4.
- Запускает игру через minecraft-launcher-lib.
- Открывает папку игры кнопкой внизу.

ОГРАНИЧЕНИЯ И ВАЖНО:
- Сейчас предусмотрен только офлайн-режим с ником. Это НЕ Microsoft-авторизация и не даст зайти на большинство серверов с online-mode.
- Для игры требуется установленная Java подходящей версии (для Minecraft 1.21.4 нужна Java 21). Этот проект пока не поставляет Java автоматически.
- Нужен интернет при первом запуске.
- Minecraft не включён в приложение; он скачивается из официальных источников при нажатии «ИГРАТЬ».
- EXE не был скомпилирован/протестирован в этой среде. Соберите его на Windows с помощью BUILD_EXE.bat.
- Не используйте этот запускатель для обхода защиты или читов.

Сборка:
1. На Windows установите Python 3.10+ только для сборки.
2. Дважды нажмите BUILD_EXE.bat.
3. Готовый файл будет в dist\AKYR Client.exe.
4. Передайте пользователю только EXE; Java должна быть установлена на компьютере пользователя.

Это прототип настоящего запуска Minecraft, не официальный Mojang/Microsoft launcher.

Python 3.10:
- Облачная сборка использует Python 3.10.
- PyInstaller включает интерпретатор Python и нужные модули внутрь AKYR Client.exe.
- На компьютере пользователя отдельно устанавливать Python не нужно.
- Сам Python не является установщиком Minecraft; Java 21 и интернет для первого скачивания игры всё ещё нужны.
